# 商业化诊断 · 渠道策略 · 转化漏斗 · 定价框架

> Agent 3（商业化诊断）的专业认知参考。涵盖渠道分布、商业化模式、定价策略、转化漏斗、动作-转化关联诊断。

## 1. 渠道分布分析维度

### 产品渠道类型

| 渠道类型 | 具体形式 | 典型产品 |
| --- | --- | --- |
| API/开发者平台 | RESTful API、SDK、开发者文档 | OpenAI、Claude、DeepSeek |
| 插件/应用市场 | 官方市场、第三方生态 | ChatGPT Plugins、Notion集成 |
| 硬件集成 | 智能设备、操作系统内置 | Apple Intelligence、小米AI |
| B端渠道 | 企业版、SI/ISV 合作 | Microsoft Copilot、文心 |
| 分销网络 | 代理商、OEM、白标 | 各类垂直行业AI方案 |
| 应用商店 | App Store、Google Play、安卓市场 | C端AI应用 |
| 浏览器扩展 | Chrome/Edge 扩展 | 各类AI助手 |
| Web直达 | 官网直接使用 | 大部分AI产品 |

### 渠道分析要点

- 渠道覆盖广度（多少种渠道）
- 各渠道贡献度（流量/收入占比）
- 渠道独占性（是否有排他合作）
- 渠道增长潜力
- 渠道成本结构

## 2. 生态合作分析框架

### 合作类型

- **平台集成**：被主流平台原生集成（如 Slack、Notion、飞书）
- **模型供应**：作为底层能力供应给其他产品
- **渠道合作**：与分发渠道的流量/推广合作
- **技术联盟**：与技术厂商的联合方案
- **行业生态**：垂直行业的解决方案合作

### 开发者生态建设

- SDK/API 完善度
- 开发者文档质量
- 社区活跃度（GitHub stars、Discord 人数、论坛帖量）
- 开发者活动（Hackathon、DevDay）
- 第三方应用/插件数量与质量

## 3. 商业化模式分析

### AI 产品商业化路径

| 路径 | 特点 | 代表 | 关键指标 |
| --- | --- | --- | --- |
| C端订阅 | 个人用户月/年费 | ChatGPT Plus、Midjourney | 付费率、ARPU、留存 |
| B端定制 | 企业版/私有部署 | Azure OpenAI、文心企业版 | 客单价、续约率 |
| API平台 | 按用量计费 | OpenAI API、Claude API | 调用量、开发者数 |
| Freemium | 免费+增值 | Notion AI、Perplexity | 转化率、免费用户价值 |
| 广告 | 流量变现 | AI搜索+广告 | DAU、广告填充率 |

### 定价策略分析

- 价格层级设计（Free/Pro/Team/Enterprise）
- 免费档慷慨度（对拉新的作用）
- 付费转化钩子（什么驱动付费）
- 价格锚点设置
- 与竞品的价格站位（高/平/低）
- 调价历史与节奏

## 4. 商业化成熟度判断

### PMF 验证信号

- 有机增长 > 付费获客（用户自发推荐）
- 付费留存 > 60%（月度）
- NPS > 40
- 用户愿意为核心功能付费（非被迫）

### 成熟度评估维度

| 维度 | 早期 | 中期 | 成熟 | 可获取性 |
| --- | --- | --- | --- | --- |
| 收入规模 | <$1M ARR | $1M-$50M ARR | >$50M ARR | 🔴 通常未公开（上市公司除外） |
| 定价稳定性 | 频繁调整 | 基本稳定 | 体系完善 | 🟡 需通过 Web Archive / 媒体报道追溯调价历史 |
| 付费转化率 | <2% | 2%-10% | >10% | 🔴 通常未公开 |
| 收入结构 | 单一 | 2-3种 | 多元化 | 🟡 可通过产品形态和定价页推断 |
| 客户层次 | 个人为主 | 个人+SMB | 个人+SMB+企业 | 🟢 可通过定价页和客户案例判断 |
| 单位经济 | 亏损 | 接近盈亏平衡 | 正向 | 🔴 通常未公开 |

### LTV 估算方法

- LTV = ARPU × 平均生命周期月数
- 平均生命周期 = 1 / 月流失率
- LTV/CAC > 3 为健康水平
- AI 产品特殊性：token 成本高，需关注毛利率

## 5. 渠道策略类型

### PLG（产品驱动增长）

- 特征：免费体验→自然传播→自助升级
- 适用：C端/SMB、产品体验即卖点
- 指标：注册→激活→付费转化漏斗
- 代表：Notion、Figma、ChatGPT

### SLG（销售驱动增长）

- 特征：销售团队→企业客户→大单
- 适用：企业版、高客单价、定制需求
- 指标：SQL、ACV、销售周期
- 代表：Azure OpenAI、Glean

### 合作伙伴生态

- 特征：通过合作方触达用户
- 适用：能力型产品（API/模型）
- 指标：合作方数量、间接收入
- 代表：OpenAI（通过Microsoft）

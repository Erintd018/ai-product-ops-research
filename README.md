# AI 产品运营研究 Skill

> 多 Agent 协作 + MCP 实时搜索 + 专家讨论环节，自动完成 AI 产品三维诊断并与用户共创运营策略。

---

## 它能做什么

输入一个 AI 产品名，自动完成：

1. **产品定位与竞争态势** — 这个产品在哪、对手在哪、趋势往哪走
2. **用户分析与增长诊断** — 用户是谁、体验如何、增长卡在哪
3. **商业化诊断** — 挣钱路径通不通、断在哪
4. **策略综合** — 与用户讨论核心命题，共创 90 天运营策略

## 工作流

| Phase | 内容 | 产出 |
|-------|------|------|
| **0 · 摸底** | Product Discovery + 关键词矩阵 | 产品定位确认 |
| **1 · 竞争态势** | Agent 1 分析市场格局 | 竞品列表 + 市场全景 |
| **2 · 用户 + 商业化** | Agent 2 + Agent 3 并行 | 用户诊断 + 商业化诊断 |
| **3 · 质量审核** | Agent Q 逐份审核 | 达标/打回修订 |
| **4 · 策略综合** | 提炼核心命题 → **暂停讨论** → 产出策略 | 90 天运营策略 |

## 核心原则

- **数据有源** — 每个数字必须有信源，不可编造
- **"搜不到"≠"不存在"** — 未获取时标注原因，不做否定判断
- **竞品多源交叉验证** — 至少 2-3 种搜索方式确认
- **Benchmark 批判性看待** — 排名≠用户选择理由
- **派系壁垒** — 渠道建议只推荐可行路径
- **先验证再行动** — 不凭产品名猜测赛道

## MCP 工具依赖

| 工具 | 用途 | 限流 |
|------|------|------|
| **Exa** | 语义搜索（竞品、融资、新闻） | 无明确限制 |
| **Firecrawl** | URL 爬取（官网、定价页） | 按 credits 计费 |
| **Tavily** | 实时搜索（舆情、口碑） | 100 RPM（Dev） |

配置文件：项目根目录 `.mcp.json`
